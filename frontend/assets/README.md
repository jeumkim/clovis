# frontend/assets

`send.html` 헤더는 이 폴더의 `hyundai-glovis-brand-guide.png`를 사용합니다.

실제 현대글로비스 브랜드 가이드 이미지 파일을 이 경로에 넣어주세요:

```
frontend/assets/hyundai-glovis-brand-guide.png
```

이 저장소에는 실제 브랜드 자산을 임의로 만들어 넣지 않았습니다(로고를
임의 글꼴로 흉내 내는 것을 방지하기 위함). 이미지가 없는 동안
`send.html`은 이미지 로드 실패를 감지해 자동으로 "현대글로비스" 일반
텍스트로 대체 표시하며, 화면 동작에는 영향이 없습니다.
